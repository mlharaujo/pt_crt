After extracting the .zip file (source: https://unfccc.int/sites/default/files/resource/PRT-CRT-2026-V1.0.zip), one should have a folder containing 34 .xlsx files (corresponding to years 1990 - 2024), called "PRT-CRT-2026-V1.0". 

Running the python script scrape.py from the directory containing this folder will produce a .csv file (prt_crt_2026.csv) containing all greenhouse gas (GHG) emissions data from these 34 files (although currently, not all sheets are included yet).

When all sheets are included, this will consist of all GHG emissions in Portugal between 1990 and 2024, as reported to the UNFCCC in 2026.
